# Salar Textile — React (Vite)

```bash
npm install
npm run dev       # start dev server
npm run build     # production build -> dist/
npm run preview   # preview the production build
```

## Structure
- `src/App.jsx` — all state (cart, wishlist, filters, search, sort, toast)
- `src/data.js` — products, categories, reviews, nav links (edit content here)
- `src/components/` — Header, Hero, Categories, Products, ProductCard, Promo, Reviews, Newsletter, Footer, etc.
- `src/styles.css` — all styling (same class names as the HTML version)
- `src/assets/` — all photos as real image files
